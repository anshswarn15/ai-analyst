# 25-second submission demo

Use the bundled sample data and record at 1440×900 or larger. Keep the browser
zoom at 100%, hide personal bookmarks/notifications, and make sure a real LLM
key is configured before recording.

| Time | On screen | Say or show |
|---|---|---|
| 0–3 s | DataPilot landing page | “DataPilot is an AI data analyst for CSV data.” |
| 3–6 s | Click **Load sample data** | “It accepts multiple files and profiles them automatically.” |
| 6–12 s | Ask: `Which region generated the highest revenue?` | Show live tool progress, the written answer, and the generated SQL result. |
| 12–17 s | Ask: `Show monthly sales trends.` | Show the chart artifact and expandable reasoning trace. |
| 17–21 s | Open **Data quality** | “It catches real quality issues and gives each table a score.” |
| 21–25 s | Open **Dashboard**, then click **Export report** | “The same session also provides a dashboard and an auditable Markdown export.” |

## Capture before submitting

Save three screenshots to `docs/images/` using these exact names:

- `chat.png` — a completed answer with a chart or SQL result and the reasoning trace visible.
- `anomalies.png` — the anomaly report, including expected range and explanation.
- `dashboard.png` — the dashboard tab with KPIs and charts.

Upload the 10–30 second MP4 or unlisted video, then replace the two placeholders
at the top of `README.md`: **Live demo** (if deployed) and **Demo video**.
